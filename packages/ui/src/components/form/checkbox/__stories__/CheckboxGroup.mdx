    ## **Purpose and Context**

    `CheckboxGroup` is useful when you need to present multiple related boolean options and allow the user to pick any number of them. It groups items for accessibility and simplifies controlled/uncontrolled state handling.

    - **Grouping**: Presents semantically related options as a single group.
    - **State patterns**: Supports both controlled (`value`) and uncontrolled (`defaultValue`) usage.
    - **Disabled handling**: Accepts a `disabled` prop to disable all items, and individual options may be disabled.
    - **Layout**: Use the `layout` prop to switch between vertical (default) and horizontal arrangement. If you provide a custom `className`, the layout variant is not applied.

    ## **FAQ**

    ### **How do I use this in a `Form`?**

    When integrating with form libraries like `react-hook-form`, map the array of selected values to the form field. Because `CheckboxGroup` emits an array of strings via `onChange`, you can directly use the array as the field value.

    <Canvas.Source>
      <Source className="my-0!" dark code={`
// Pseudocode with react-hook-form
import { useForm } from 'react-hook-form'
import CheckboxGroup from '@clera-ui/form'

function FormExample() {
  const { control, setValue } = useForm()

  // when CheckboxGroup changes, call setValue('selectedOptions', values)
  return (
    <CheckboxGroup
      options={[{value:'a', label:'A'}]}
      onChange={(vals) => setValue('selectedOptions', vals)}
    />
  )
}
