# BarChart

A lightweight horizontal bar chart for comparing categorical values. Each row renders a label, a proportionally-sized bar, and an optional numeric value.

## When to use

- Comparing a small set (≲ 10) of named values at a glance.
- Showing breakdowns where the relative size matters more than precise numbers.
- Inside dashboards or KPI cards alongside other primitives from `@clera/ui`.

For dense time-series, scatter plots, or anything interactive, reach for a fuller charting primitive (coming later in `@clera/charts`).
