    ## **When To Use**
    The Bar chart visualizes and compares a small set of named values — revenue by month, traffic by source, votes by option. It is powered by [Apache ECharts](https://echarts.apache.org/) and resolves every color from `@clera/tokens`, so it adapts to light/dark mode automatically.

    In {config.title}, the chart is highly flexible and adapts to different contexts through its props:

      - **Direction**: Choose the orientation that fits your data.
        - `vertical`: Columns — category on the x-axis, value on the y-axis. Best for time series.
        - `horizontal`: Bars — category on the y-axis, value on the x-axis. Best for long labels or rankings.

      - **Palette & Variant**: Control coloring.
        - `palette="brand"`: A single primary color for every bar (default).
        - `palette="categorical"`: Cycles the eight design-system categorical colors.
        - `variant` per datum: Recolor a single bar (`primary`, `success`, `info`, `warning`, `destructive`, `neutral`).

    - **Grouped Series**: Provide `categories` + `series` to compare more than one measure per category, with an interactive **legend**.
    - **Value Axis & Grid Lines**: Turn on `showValueAxis` for a formatted scale; toggle `gridLines` independently.
    - **Value Labels**: Show the number on each bar with `showValues` (usually off when the value axis is on).
    - **Reference Line**: Mark a target or average with `referenceLine`. The label renders as a pill that stays clear of the bars.
    - **Sorting**: Order bars by value with `sort` (`none`, `asc`, `desc`).
    - **Loading & Empty**: Show a spinner with `loading`, or a centered message with `emptyMessage` when there is no data.
    - **Animation**: Bars grow in on load via `animate`; it is automatically disabled under `prefers-reduced-motion`.

    These options make the Bar a versatile building block for dashboards and KPI cards, while staying consistent with the rest of the system.

    ### **Waterfall**
    A waterfall is a stacked chart with a transparent **base** series carrying the running offset and a visible **change** series on top. Mark the base series `silent` so it stays out of the tooltip, labels, and legend.
    <Canvas>
      <Canvas.Story>
        <Story of={BarStories.Waterfall} />
      </Canvas.Story>

      <Canvas.Source>
        <Source className="my-0!" dark code={`
          import { Bar } from '@clera/charts'

          // Turn deltas into a transparent base + a visible change series.
          const steps = [
            { label: 'Open', delta: 3200 },
            { label: 'Sales', delta: 4800 },
            { label: 'Refunds', delta: -1500 },
            { label: 'Payroll', delta: -2600 },
            { label: 'Marketing', delta: -1100 },
            { label: 'Net', delta: 900 },
          ]
          let running = 0
          const base = steps.map((s) => {
            const before = running
            running += s.delta
            return Math.min(before, running)
          })
          const change = steps.map((s) => Math.abs(s.delta))

          const CashFlow = () => (
            <Bar
              direction="vertical"
              stacked
              showLegend={false}
              showValueAxis
              formatValue={(v) => '$' + (v / 1000).toFixed(1) + 'k'}
              categories={steps.map((s) => s.label)}
              series={[
                { name: 'base', data: base, color: 'transparent', silent: true },
                { name: 'Change', data: change, variant: 'primary' },
              ]}
            />
          )

          export default CashFlow
        `} />
      </Canvas.Source>
    </Canvas>

    ### **Drilldown (multi-level)**

    Drilldown is a usage pattern, not a prop: the `useBarDrilldown` helper holds a tree and swaps which level's `data` is shown, while `onBarClick` drills in and a breadcrumb jumps back. It supports any depth — here regions → countries → cities.
    <Canvas>
      <Canvas.Story>
        <Story of={BarStories.Drilldown} />
      </Canvas.Story>

      <Canvas.Source>
        <Source className="my-0!" dark code={`
          import { Bar, useBarDrilldown } from '@clera/charts'

          const tree = [
            { label: 'Americas', value: 1200, children: [
              { label: 'USA', value: 800, children: [
                { label: 'New York', value: 400 },
                { label: 'San Francisco', value: 250 },
              ] },
              { label: 'Canada', value: 250 },
            ] },
            { label: 'EMEA', value: 900, children: [/* ... */] },
          ]

          const Sales = () => {
            const { data, path, onBarClick, drillTo } = useBarDrilldown(tree)
            return (
              <div>
                <nav>
                  {path.map((label, i) => (
                    <button key={i} onClick={() => drillTo(i)}>{label}</button>
                  ))}
                </nav>
                <Bar data={data} showValueAxis onBarClick={onBarClick} />
              </div>
            )
          }

          export default Sales
        `} />

    ### **Axis breaks**

    When some series dwarf the rest, `axisBreaks` collapses ranges of the value axis with a zig-zag break so small and large series stay readable together. Each break is `{ start, end, gap? }` and you can pass several. With `axisBreakExpandable` (on by default), **clicking a break area expands that range** to inspect it, and a **“Collapse breaks” button** appears to restore the view. Customise that button with `axisBreakCollapse` — `text`, `offset` `[left, top]`, `textStyle` and `buttonStyle` all override the theme-aware defaults.

    ## **FAQ**

    #### **How do I show the value axis and grid lines?**

    Set `showValueAxis` to render the numeric axis with a `formatValue`-formatted scale. Grid lines follow the axis by default; toggle them on their own with `gridLines`.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar showValueAxis data={data} />
        <Bar showValueAxis gridLines={false} data={data} />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I render grouped bars with a legend?**

    Provide shared `categories` and one or more `series`. Each series renders as a legend entry with its own color. Use `showLegend` to hide it, and `legendPosition` to move it to the `top`, `bottom`, `left`, or `right` — margin is reserved automatically so it never overlaps the plot.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar
          showLegend
          legendPosition="right"
          categories={['Q1', 'Q2', 'Q3', 'Q4']}
          series={[
            { name: 'New', data: [28000, 24500, 31200, 40100] },
            { name: 'Returning', data: [14000, 14000, 20000, 32000] },
          ]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I recolor individual bars?**

    Colors resolve in this order: a custom `color` on the datum/series → its `variant` (a token) → the chart `palette` (token default). So use `variant` to stay on-token, switch the whole chart to `palette="categorical"`, or pass a raw `color` for a one-off.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar
          data={[
            { label: 'Mobile', value: 482, variant: 'success' },
            { label: 'Desktop', value: 318, color: '#7c3aed' },
          ]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I create a stacked bar chart?**

    Use grouped mode (`categories` + `series`) and add `stacked`. Series stack into one bar per category; only the outer segment is rounded and labels render inside the segments.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar
          stacked
          showLegend
          categories={['Q1', 'Q2']}
          series={[
            { name: 'New', data: [28000, 24500] },
            { name: 'Returning', data: [14000, 14000] },
          ]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I show a background rail behind each bar?**

    Set `showTrack` for a faint full-length rail (great for usage/quota meters). Pair it with `max` for a meaningful 100%, and override the rail color with `trackColor` if needed (it defaults to a theme token).
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar
          showTrack
          max={100}
          formatValue={(v) => v + '%'}
          data={[{ label: 'Storage', value: 82, variant: 'warning' }]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I add a target or average line?**

    Pass `referenceLine={{ value, label? }}`. The label renders as a pill positioned at the end of the line so it never overlaps the bar color, and it stays horizontal in both orientations.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar referenceLine={{ value: 55000, label: 'Target' }} data={data} />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I format values as currency or percentages?**

    Provide a `formatValue` callback. It is applied consistently to bar labels, value-axis ticks, the reference line, and the tooltip.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar formatValue={(v) => '$' + (v / 1000).toFixed(1) + 'k'} data={data} />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I react to bar clicks or hover?**

    Pass `onBarClick`, `onBarHover`, or `onBarLeave`. Each receives the datum and its index (mapped back to the original, unsorted data), so you can drive selection, tooltips, or a drilldown.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar
          data={data}
          onBarClick={(datum, index) => console.log('click', datum, index)}
          onBarHover={(datum) => setActive(datum.label)}
          onBarLeave={() => setActive(null)}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I access the ECharts instance directly?**

    Pass `onReady` — it's called once on mount with the underlying ECharts instance. Use it as an escape hatch for anything the props don't cover (dataZoom, brush selection, drilldown, custom events) without forking the component.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar
          data={data}
          onReady={(chart) => {
            chart.dispatchAction({ type: 'highlight', dataIndex: 0 })
            chart.on('datazoom', (e) => console.log(e))
          }}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I show loading and empty states?**

    Set `loading` to overlay a spinner while data is being fetched. When `data` is empty, a centered `emptyMessage` is shown instead of the chart.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar loading data={data} />
        <Bar data={[]} emptyMessage="No revenue yet" />
      `} />
    </Canvas.Source>

    <br />

    #### **Does the chart adapt to light and dark themes?**

    Yes. All colors resolve from `@clera/tokens` CSS variables at render time, and the chart re-resolves them when the active theme changes — no manual theming required.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Bar data={data} />
      `} />
    </Canvas.Source>
