    ## **When To Use**
    The Line chart visualizes trends — a stock price through the day, traffic over the week, a metric over the year. It is powered by [Apache ECharts](https://echarts.apache.org/) and resolves every color from `@clera/tokens`, so it adapts to light/dark mode automatically. Where [`Combo`](?path=/docs/charts-combo--docs) mixes bars and lines on a category axis, `Line` specializes in time-series and trend work.

    In {config.title}, the chart adapts to different contexts through its props:

      - **X axis**: Choose how points are positioned.
        - `category`: Evenly spaced labels — best for periodic data (days, months).
        - `time`: A real time axis that positions each point by its timestamp — pass `[x, y]` pairs. Best for intraday or irregular data.

      - **Curve**: Choose the line shape.
        - `straight`: Segments between points.
        - `smooth`: A spline through the points.
        - `stepped`: Holds each value until the next — for things that change in jumps.

    - **Area Fill**: Add `area` (a flat tint) or `area="gradient"` (fades to transparent) under any line; override per series.
    - **Threshold Coloring**: Color the line green-above / red-below a baseline with `threshold` — the classic finance look.
    - **Annotations**: Mark a `referenceLine` (target, SLA, previous close) or shade a `markArea` (an incident window, after-hours).
    - **Zoom**: Turn on `zoom` to page through long series with a slider plus scroll/drag.
    - **Sparkline**: The `sparkline` preset strips everything down to a pure trend line for KPI cards.
    - **Loading & Empty**: Show a spinner with `loading`, or a centered message with `emptyMessage` when there is no data.

    These options make the Line a versatile building block for dashboards, finance, and observability, while staying consistent with the rest of the system.

    ### **Stock price (intraday)**

    A Google-Finance-style intraday chart on a real `time` axis: a single line with a gradient area fill, a dashed **previous close** reference line, and a color driven by whether the day is up or down. Points stay hidden until you hover.

        <Source className="my-0!" dark code={`
          import { Line } from '@clera/charts'

          const PREV_CLOSE = 178.6

          const StockChart = ({ points, last }) => (
            <Line
              xAxisType="time"
              area="gradient"
              series={[{ name: 'ACME', variant: last >= PREV_CLOSE ? 'success' : 'destructive', data: points }]}
              referenceLine={{ value: PREV_CLOSE, label: 'Prev close $' + PREV_CLOSE.toFixed(2) }}

          export default StockChart

    ### **Y-axes (`yAxes`)**

    The y-axes are a list — any number on the left and/or right, each self-describing its `name` (title), `side`, scale, `format`, and its own title `position` / `orientation`. Series bind to an axis by its `id` (or array index) via `series[].yAxis`; a series with no `yAxis` uses the first axis. Multiple axes on the same side auto-offset outward, and each axis's title gutter is reserved so nothing overlaps the ticks or the zoom slider. (The x-axis is a single `xAxis` object; several x-axes are `MultiXLine`.)

    Here flow reads off the left axis and the rainfall axis on the right is `inverse`d so showers fall from the top:

    ### **Live streaming**

    A new reading arrives every second and the oldest drops off. Grab the chart with `onReady` and push just the changed `xAxis.data` / `series.data` on an interval — ECharts animates each point to its new slot.
    <Canvas>
      <Canvas.Story>
        <Story of={LineStories.LiveStreaming} />
      </Canvas.Story>

      <Canvas.Source>
        <Source className="my-0!" dark code={`
          import { useEffect, useRef, useState } from 'react'
          import { Line } from '@clera/charts'

          const Live = () => {
            const chartRef = useRef(null)
            const [seed] = useState(() => makeWindow())

            useEffect(() => {
              const live = { categories: [...seed.categories], values: [...seed.values] }
              const id = setInterval(() => {
                live.categories = [...live.categories.slice(1), clock(new Date())]
                live.values = [...live.values.slice(1), nextReading()]
                chartRef.current?.setOption({
                  xAxis: { data: live.categories },
                  series: [{ data: live.values }],
                })
              }, 1100)
              return () => clearInterval(id)
            }, [seed])

            return (
              <Line
                curve="smooth"
                area
                categories={seed.categories}
                series={[{ name: 'Throughput', variant: 'primary', data: seed.values }]}
                onReady={(chart) => { chartRef.current = chart }}
              />
            )
          }

          export default Live
        `} />
      </Canvas.Source>
    </Canvas>

    ## **FAQ**

    #### **How do I use a real time axis?**

    Set `xAxisType="time"` and give each series `[x, y]` pairs, where `x` is a timestamp (ms) or a date string. The axis spaces points by their actual time, and `formatX` formats the ticks and tooltip header.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line
          xAxisType="time"
          formatX={(v) => new Date(v).toLocaleDateString()}
          series={[{ name: 'Price', data: [[1710420600000, 179.1], [1710420900000, 179.4]] }]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I color a line above/below a baseline?**

    Pass `threshold={{ value, above?, below? }}`. Segments at or above `value` use the `above` color, below use `below` — each accepts a token variant (`success`, `destructive`, …) or a raw color. Applies to the first series, which is drawn with straight segments (per-segment color mapping does not support smoothing).
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line
          threshold={{ value: 0, above: 'success', below: 'destructive' }}
          series={[{ name: 'P&L', data: pnl }]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I add an area fill?**

    Set `area` for a flat tint or `area="gradient"` to fade to transparent. Set it on the whole chart, or per series with `series[].area`. Give two or more series a shared `stack` name to stack their areas.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line area="gradient" series={[{ name: 'Visits', data }]} />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I mark a target, SLA, or previous close?**

    Pass `referenceLine={{ value, label?, axis?, color? }}` (or an array for several). It defaults to the value (`y`) axis and renders a dashed line with a pill label.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line
          referenceLine={[{ value: 80, label: 'SLA' }, { value: 95, label: 'Critical', color: 'rgb(220, 38, 38)' }]}
          series={[{ name: 'CPU', data: cpu }]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I shade a region?**

    Pass `markArea={{ from, to, label?, color?, axis? }}` (or an array). It defaults to a vertical band over the x-axis — handy for an incident window or an after-hours range.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line
          markArea={{ from: '13:30', to: '13:39', label: 'Incident' }}
          series={[{ name: 'Latency', data }]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I render a sparkline?**

    Set `sparkline` to strip the axes, grid, legend, and tooltip down to a pure trend line. Pair it with a short, fixed `height` and an `area` fill.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line sparkline height={48} area series={[{ name: 'MRR', data }]} />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I handle long series?**

    Turn on `zoom` for a bottom slider plus scroll-to-zoom and grab-to-pan. Rendering uses LTTB down-sampling, so hundreds of points stay smooth.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line xAxisType="time" zoom series={[{ name: 'DAU', data: yearOfDays }]} />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I move the y-axis to the right?**

    Give the axis `side: 'right'` — `yAxes={[{ side: 'right' }]}` — and it (with its label space) flips to the right. The same array holds a left-and-right pair, or several axes, each with its own `side`.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line yAxes={[{ side: 'right' }]} series={[{ name: 'Views', data }]} />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I put icons on the x-axis labels (like YouTube analytics)?**

    Use the `xAxisLabel` escape hatch. Its `formatter` is the render function — return ECharts rich-text markup — and `rich` defines the style blocks, including images via `backgroundColor.image` (any URL or data URI, e.g. a video thumbnail). Available on `Bar`, `Line`, and `Combo`.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line
          categories={['Mon', 'Tue', 'Wed']}
          series={[{ name: 'Views', data }]}
          xAxisLabel={{
            formatter: (value) => '{icon|}\\n{label|' + value + '}',
            rich: {
              icon: { height: 16, width: 16, backgroundColor: { image: thumbUrl } },
              label: { fontSize: 12 },
            },
          }}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I access the ECharts instance directly?**

    Pass `onReady` — it's called once on mount with the underlying ECharts instance. Use it for streaming updates or anything the props don't cover.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line
          series={[{ name: 'Live', data }]}
          onReady={(chart) => chart.setOption({ series: [{ data: next }] })}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **Does the chart adapt to light and dark themes?**

    Yes. All colors resolve from `@clera/tokens` CSS variables at render time, and the chart re-resolves them when the active theme changes — no manual theming required.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Line series={[{ name: 'Visits', data }]} />
      `} />
    </Canvas.Source>
