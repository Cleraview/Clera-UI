    # Combo

    To overlay different series types on a shared category axis.
    <DocInfo importStatement={`import { Combo } from '@clera/charts'`} sourcePath={`components/combo`} />

    <br />

    ## **When To Use**
    The Combo chart mixes `bar`, `line`, and `area` series on one cartesian grid — revenue bars with an orders line, rainfall bars with a temperature line, and so on. It is powered by [Apache ECharts](https://echarts.apache.org/), shares the same `useEChart` runtime and `@clera/tokens` colors as `Bar`, and adapts to light/dark mode automatically.

    In {config.title}, it is driven entirely by the `series` array:

      - **Series types**: Each series picks its own `type`.
        - `bar`: Discrete values (rounded columns).
        - `line`: A trend line, optionally `smooth`.
        - `area`: A line with a translucent fill.

      - **Dual axes**: Set `axis: 'right'` on a series to plot it against a second value axis — ideal for two different units (e.g. mm vs. °C). Configure each side with `leftAxis` / `rightAxis` (`{ name, min, max, format }`).
      - **Per-series color**: `variant` (a design-system token) or a raw `color`; otherwise the categorical palette is used.
      - **Shared tooltip**: Hovering a category lists every series, each formatted by its own axis.
      - **Legend, grid, labels, loading, empty, animation**: Same ergonomics as `Bar`.
      - **Escape hatch**: `onReady(chart)` exposes the ECharts instance for anything else.

    ## **FAQ**

    #### **How do I plot two different units?**

    Put one series on the right axis with `axis: 'right'`, then configure `leftAxis`/`rightAxis` independently — each `format` applies to its own ticks and tooltip rows.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Combo
          categories={categories}
          leftAxis={{ name: 'mm' }}
          rightAxis={{ name: '°C', format: (v) => v + '°' }}
          series={[
            { name: 'Rainfall', type: 'bar', data: rain },
            { name: 'Temp', type: 'line', axis: 'right', data: temp },
          ]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I make a smooth or filled line?**

    Use `type: 'line'` with `smooth: true`, or `type: 'area'` for a translucent fill under the line.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Combo
          categories={categories}
          series={[{ name: 'Active', type: 'area', smooth: true, data }]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I access the ECharts instance?**

    Pass `onReady` — it fires once on mount with the instance, so you can wire up dataZoom, brush, or any ECharts API directly.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Combo categories={categories} series={series} onReady={(chart) => { /* ... */ }} />
      `} />
    </Canvas.Source>
