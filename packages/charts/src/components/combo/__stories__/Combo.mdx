    # Combo

    To overlay different series types on a shared category axis.
    <DocInfo importStatement={`import { Combo } from '@clera/charts'`} sourcePath={`components/combo`} />

    <br />

    ## **When To Use**
    The Combo chart mixes `bar`, `line`, and `area` series on one cartesian grid — revenue bars with an orders line, rainfall bars with a temperature line, and so on. It is powered by [Apache ECharts](https://echarts.apache.org/), shares the same `useEChart` runtime and `@clera/tokens` colors as `Bar`, and adapts to light/dark mode automatically.

    In {config.title}, it is driven entirely by the `series` array:

      - **Series types**: Each series picks its own `type`.
        - `bar`: Discrete values (rounded columns).
        - `line`: A trend line, optionally `smooth`.
        - `area`: A line with a translucent fill.

      - **Multiple axes**: Declare the y-axes in `yAxes` — one or more, each with a `side` (`left`/`right`), `name`, scale, and `format`. Bind a series to one with `series[].yAxis` (its `id` or index) to plot two units (e.g. mm vs. °C) or several. Same-side axes stack outward and take on their series' color.
      - **Per-series color**: `variant` (a design-system token) or a raw `color`; otherwise the categorical palette is used.
      - **Shared tooltip**: Hovering a category lists every series, each formatted by its own axis.
      - **Legend, grid, labels, loading, empty, animation**: Same ergonomics as `Bar`.
      - **Escape hatch**: `onReady(chart)` exposes the ECharts instance for anything else.

    ### **Multiple Y axes**

    When two units aren't enough, add more entries to `yAxes`. Each axis sets its own `side` (`left`/`right`) and `format`; same-side axes stack outward automatically. Series point at one with `yAxis: <index>` (or its `id`), and each axis adopts its series' color so they're easy to tell apart.

    ### **Dynamic data**

    For a smooth streaming chart, grab the ECharts instance with `onReady` and push just the changed `xAxis.data` / `series.data` on an interval. ECharts merges the update and animates each bar and point to its new slot, so the series slides to the left as the oldest reading drops off — much nicer than re-rendering the whole option.
    <Canvas>
      <Canvas.Story>
        <Story of={ComboStories.DynamicData} />
      </Canvas.Story>

      <Canvas.Source>
        <Source className="my-0!" dark code={`
          import { useEffect, useMemo, useRef } from 'react'
          import { Combo } from '@clera/charts'

          const clock = () => new Date().toLocaleTimeString(undefined, { hour12: false })
          const price = () => +(Math.random() * 10 + 5).toFixed(1)
          const orders = () => Math.round(Math.random() * 1000)

          const Live = () => {
            const chartRef = useRef(null)
            const seed = useMemo(() => ({
              categories: Array.from({ length: 10 }, clock),
              price: Array.from({ length: 10 }, price),
              orders: Array.from({ length: 10 }, orders),
            }), [])

            useEffect(() => {
              const live = { ...seed }
              const id = setInterval(() => {
                live.categories = [...live.categories.slice(1), clock()]
                live.price = [...live.price.slice(1), price()]
                live.orders = [...live.orders.slice(1), orders()]
                chartRef.current?.setOption({
                  xAxis: { data: live.categories },
                  series: [{ data: live.orders }, { data: live.price }],
                })
              }, 2100)
              return () => clearInterval(id)
            }, [seed])

            return (
              <Combo
                categories={seed.categories}
                yAxes={[
                  { name: 'Price', min: 0, max: 30 },
                  { name: 'Orders', side: 'right', min: 0, max: 1200 },
                ]}
                series={[
                  { name: 'Dynamic Bar', type: 'bar', yAxis: 'right', data: seed.orders, variant: 'primary' },
                  { name: 'Dynamic Line', type: 'line', data: seed.price, variant: 'warning' },
                ]}
                onReady={(chart) => { chartRef.current = chart }}
              />
            )
          }

          export default Live
        `} />
      </Canvas.Source>
    </Canvas>

    ## **FAQ**

    #### **How do I plot two different units?**

    Declare two `yAxes` (the second with `side: 'right'`) and bind a series to it with `yAxis: 'right'` — each axis's `format` applies to its own ticks and tooltip rows.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Combo
          categories={categories}
          yAxes={[
            { name: 'mm' },
            { name: '°C', side: 'right', format: (v) => v + '°' },
          ]}
          series={[
            { name: 'Rainfall', type: 'bar', data: rain },
            { name: 'Temp', type: 'line', yAxis: 'right', data: temp },
          ]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I make a smooth or filled line?**

    Use `type: 'line'` with `smooth: true`, or `type: 'area'` for a translucent fill under the line.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Combo
          categories={categories}
          series={[{ name: 'Active', type: 'area', smooth: true, data }]}
        />
      `} />
    </Canvas.Source>

    <br />

    #### **How do I access the ECharts instance?**

    Pass `onReady` — it fires once on mount with the instance, so you can wire up dataZoom, brush, or any ECharts API directly.
    <Canvas.Source>
      <Source className="my-0!" dark code={`
        <Combo categories={categories} series={series} onReady={(chart) => { /* ... */ }} />
      `} />
    </Canvas.Source>
